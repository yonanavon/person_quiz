# שאלון היכרות ואבחון אישיות לתלמידים

פלטפורמה לשאלון אישיות לתלמידים (בנים, כיתות ז'-ח') המבוסס על מודלים מוכרים:
ארבעת סגנונות התקשורת, ששת ה-P של ריק לאבוי, העדפות למידה וסולמות רגשיים-חברתיים.
פירוט מלא של השאלות והניקוד: [docs/assessment-design.md](docs/assessment-design.md)

## הרצה מקומית

דרישה: Node.js 22.13 ומעלה.

```bash
npm install
npm start
```

- שאלון לתלמידים: http://localhost:3000
- ממשק מורה: http://localhost:3000/admin — סיסמה ברירת מחדל: `admin1234`

בהרצה מקומית הנתונים נשמרים בקובץ `data.db` (SQLite מובנה — אין צורך בהתקנה).

**צעד ראשון:** היכנסו לממשק המורה וצרו כיתה עם קוד (למשל: כיתה "ז1", קוד "7134").
את הקוד מוסרים לתלמידים יחד עם הקישור.

## משתני סביבה

| משתנה | תפקיד | ברירת מחדל |
|--------|--------|--------------|
| `ADMIN_PASSWORD` | סיסמת ממשק המורה | `admin1234` מקומית בלבד — **בפריסה חובה להגדיר (8 תווים+), אחרת השרת לא יעלה** |
| `SESSION_SECRET` | מפתח חתימת עוגיות | אקראי מקומית — **בפריסה חובה להגדיר, אחרת השרת לא יעלה** |
| `DATABASE_URL` | חיבור PostgreSQL (Railway מגדיר אוטומטית) | ללא — SQLite מקומי |
| `ANTHROPIC_API_KEY` | מפתח ל"ניתוח AI מעמיק" | ללא — הכפתור מוסתר, הניקוד המובנה עובד תמיד |
| `ANTHROPIC_MODEL` | מודל לניתוח ה-AI | `claude-opus-5` |
| `PORT` | פורט השרת | 3000 |

## פריסה ב-Railway

1. העלו את התיקייה ל-GitHub (או `railway up` עם ה-CLI).
2. ב-Railway: **New Project → Deploy from GitHub repo**.
3. הוסיפו מסד נתונים: **+ New → Database → PostgreSQL**. Railway יזריק `DATABASE_URL` אוטומטית לשירות (ודאו שהמשתנה משותף לשירות האפליקציה — Add Variable Reference).
4. הגדירו משתני סביבה בשירות האפליקציה:
   - `ADMIN_PASSWORD` — סיסמה חזקה משלכם
   - `SESSION_SECRET` — מחרוזת אקראית ארוכה (כדי שההתחברות תשרוד הפעלה מחדש)
   - `ANTHROPIC_API_KEY` — אופציונלי, להפעלת ניתוח AI
5. **Generate Domain** בהגדרות השירות — וקיבלתם קישור לשליחה לתלמידים.

> בפריסה (כשמוגדר `DATABASE_URL` או `NODE_ENV=production`) השרת מסרב לעלות ללא
> `ADMIN_PASSWORD` ו-`SESSION_SECRET`, ומוסיף `Secure` לעוגיית ההתחברות. אם הדיפלוי
> נכשל מיד — בדקו את הלוג, כנראה חסר אחד המשתנים.

## שמירה אוטומטית ונטישה

השאלות הפתוחות הן המודול האחרון, ולכן תלמיד שנוטש לפניהן היה מאבד את כל 40 התשובות הסגורות.
כדי למנוע זאת יש שתי שכבות:

1. **`localStorage`** — שחזור מקומי ("המשך מהמקום שהפסקת"), תקף 24 שעות באותו דפדפן.
2. **טיוטה בשרת** (`POST /api/submit-draft`) — נשלחת כל 5 שאלות, בכל מעבר בין מודולים, אחרי כל
   שאלה פתוחה, ובנטישה דרך `sendBeacon`. כך המורה רואה את התשובות גם אם התלמיד לא חוזר לעולם.

טיוטה נשמרת עם `submitted = 0` ומתעדכנת במקום ליצור כפילות (זיהוי לפי שם + כיתה).
בשליחה הסופית אותה שורה מתעדכנת ל-`submitted = 1`. **שליחה סופית קיימת לעולם לא נדרסת** —
תלמיד שממלא פעמיים ייווצר כרשומה נפרדת, כדי שהמורה יראה את שתיהן.

בממשק המורה שאלון שלא הושלם מסומן **⏸ לא הושלם** (תג אדום), ומוצג באנר שמסביר שהתשובות
נשמרו אוטומטית ושכדאי לבקש מהתלמיד להשלים. שאלונים כאלה **אינם נספרים** בהתפלגויות
של "תמונת כיתה", ובייצוא ה-CSV יש עמודת "סטטוס".

## אבטחה

- **הגבלת קצב התחברות:** 8 ניסיונות כושלים לכל כתובת IP בחלון של 15 דקות. הספירה בזיכרון
  ומתאפסת בהפעלה מחדש של השרת (מספיק לשרת יחיד; בריבוי אינסטנסים נדרש אחסון משותף).
- **סיסמה:** ההשוואה בזמן קבוע, כדי שלא ניתן יהיה להסיק את הסיסמה ממדידת זמני תגובה.
- **XSS:** כל טקסט שמקורו במשתמש (שם תלמיד, שם כיתה, תשובות פתוחות, פלט ה-AI) עובר
  escaping לפני הצגה בממשק המורה — ראו `esc()` ב-`public/admin.js`. **בכל קוד חדש שמזריק
  ל-`innerHTML` חובה להשתמש ב-`esc()`.**

## אתגרי חשיבה (פרופיל יכולות)

חמש תחנות קצרות (~12 דקות): חידות צורות, זיכרון הקוביות, מספרים הפוכים, מהיר וממוקד, עצור וסע.
בסוף השאלון הרגיל מוצעת לתלמיד הפניה אליהן (רשות), עם השם וקוד הכיתה בכתובת כדי שלא יקליד שוב.
התוצאות מוצגות למורה בלשונית "פרופיל יכולות" בפרופיל התלמיד, ומוזנות גם לניתוח ה-AI.

**עקרון מנחה:** אין כאן ציוני IQ ואין נורמות ארציות. האחוזון מחושב **מול הכיתה בלבד**,
ורק כשיש לפחות 5 תלמידים שהשתתפו באותה תחנה. הניסוח הוא של חוזקות וחולשות יחסיות —
סימני שאלה לבירור, לא אבחנה ולא תיוג. פירוט: [docs/cognitive-games-plan.md](docs/cognitive-games-plan.md).

## עריכת שאלות

כל השאלות נמצאות ב-`questions.js`. אפשר לערוך נוסח בחופשיות; אם משנים את **מספר** השאלות
או את המיפוי (style/p/axis/scale), הניקוד מתעדכן אוטומטית — רק שימו לב שבמודול המוטיבציה
כדאי לשמור על מספר הופעות שווה לכל מנוע (כיום 6 לכל P).
